# 数据字典

> 数据集：[Kaggle · Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
> （ULB 布鲁塞尔自由大学机器学习组，Andrea Dal Pozzolo 等，2015）
> 内容：2013 年 9 月欧洲持卡人 **48 小时**内的信用卡交易，**284,807 笔 × 31 字段**。
> 文件指纹（SHA256）见 `reports/data_quality.json`。

## 1. 原始字段（31 个）

| 字段 | 类型 | 含义 | 取值范围 / 说明 |
|---|---|---|---|
| `Time` | float64（实为整数秒） | 距数据集首笔交易的**秒数** | 0 ~ 172,792（48.00 小时）。**不是时间戳**：无日期、无时区、无真实时钟，只能做相对时段分析（相对小时 = `(Time/3600) % 24`，相对天 = `Time // 86400 + 1`） |
| `V1` ~ `V28` | float64 | PCA 变换后的匿名特征 | 均值≈0（-2.4e-15~4.9e-15）、标准差 0.33~1.96；**不可赋予业务含义**，其背后的原始字段（商户、卡种、地区等）未公开 |
| `Amount` | float64 | 交易金额（欧元） | 0 ~ 25,691.16；中位数 22.00、均值 88.35、P99 1,017.97；强右偏（偏度 16.98） |
| `Class` | int64 | 分类标签 | **0 = 正常交易，1 = 欺诈交易**。含义确认：Kaggle 官方说明 1=欺诈；数据交叉验证——Class=1 仅 492 笔（0.1727%），与真实欺诈发生率量级一致，反向理解则与常识矛盾 |

### 类别分布

| Class | 笔数 | 占比 | 金额合计（€） |
|---|---|---|---|
| 0 正常 | 284,315 | 99.8273% | 25,102,462.04 |
| 1 欺诈 | 492 | 0.1727% | 60,127.97（占总额 0.239%） |

不平衡比 ≈ **577.9 : 1**。在此比例下"全判正常"也有 99.83% Accuracy，故全项目**禁止以 Accuracy 为评价指标**。

## 2. 处理口径与派生字段

### 2.1 去重口径（阶段二建模前执行）

| 项目 | 实测 |
|---|---|
| 完全重复行 | 1,081 行（0.3796%），其中 19 行 Class=1；共 773 组 |
| Class 标签冲突 | 0 组（按 30 个特征列分组检查——对全列重复做该检查无意义） |
| 处理动作 | 仅 `drop_duplicates(keep='first')` |
| 去重后 | **283,726 行 / 473 笔欺诈**（0.1667%） |

### 2.2 `transactions_clean.parquet` 派生字段（阶段一 EDA 产物）

| 派生字段 | 含义 | 说明 |
|---|---|---|
| `is_duplicate` | 是否属于完全重复行 | 仅打标，建模前去重 |
| `is_zero_amount` | 金额是否为 0 | 1,825 笔（0.641%）。数据集无交易类型字段，无法证实业务性质（余额查询/预授权/冲正均有可能），**不做业务归因**，仅打标避免与真实小额交易混同 |
| `hour_of_day`（分析用） | 相对时段 = `(Time/3600) % 24` | 0~23 的"相对小时"，不对应真实凌晨/白天 |

### 2.3 建模特征集（阶段二，`src/features/features.py` 白名单）

| 用途 | 字段 |
|---|---|
| 特征 X（30 维） | `V1`~`V28` + `Amount` + `Time`（Time 保留以学习昼夜节律） |
| 标签 y | `Class` |
| 显式排除 | 任何 `Class` 派生列、`is_duplicate`/`is_zero_amount` 等标记列不进特征（白名单机制保证） |

### 2.4 时间切分口径

| 数据集 | 记录数 | 欺诈数 | 欺诈率 | Time 范围（秒） |
|---|---|---|---|---|
| train (70%) | 198,608 | 366 | 0.1843% | [0, 132,906] |
| val (15%) | 42,559 | 55 | 0.1292% | [132,906, 151,320] |
| test (15%) | 42,559 | 52 | 0.1222% | [151,320, 172,792] |

按 `Time` 升序整数下标切分，三集互不重叠、并集等于全集；**禁用随机切分**（防未来信息泄漏）。

## 3. 预测文件 schema（`data/processed/predictions_{val,test}_{lr,rf,xgb}.csv`）

| 字段 | 含义 |
|---|---|
| `Time` / `Amount` | 原始值（便于按时间/金额切片分析） |
| `Class` | 真实标签 |
| `predicted_probability` | 模型输出的欺诈概率（注意：XGBoost 因 `scale_pos_weight` 概率整体偏大，未校准） |
| `predicted_label` | 阈值 0.5 下的判定（1=判为欺诈） |

## 4. SQLite 表结构（`data/processed/transactions.db`）

```
transactions(
  raw_row_id  INTEGER,   -- 原始 CSV 行号（0 基）
  time_sec    REAL,      -- = Time，距首笔交易秒数
  v1 ... v28  REAL,      -- PCA 匿名特征
  amount      REAL,      -- 欧元
  class       INTEGER    -- 0=正常, 1=欺诈
)
-- 索引：class / time_sec / amount 各 1 个
-- 行数：284,807（原始口径，未去重；去重口径见 parquet）
```

## 5. 已知的字段层面限制

1. **Time 无真实时钟**：所有"时段"结论只能表述为"相对时段"；
2. **V 特征匿名**：模型结论无法做业务归因，只能做模型层面解释；
3. **无卡号/商户/地区字段**：无法构造同卡连续行为、商户集中度等强特征；
4. **仅 48 小时**：无法验证跨周/跨月稳定性与欺诈漂移。
