| 字段 | 含义 | 说明 |
|---|---|---|

| `V1`~`V28` | PCA 变换后的匿名特征 | **禁止赋予业务含义**；原始字段（商户/卡种/地区）未公开 |

## 2. 数据质量检查结果

完整报告：`reports/data_quality_report.md`（机器可读版 `reports/data_quality.json`）。

### 2.1 总体结论：质量良好，可以直接使用

| 检查项 | 结果 |
|---|---|
| 缺失值 | **0**（占比 0.0000%） |
| 字段类型 | 30 个 float64 + 1 个 int64，无字符串列，无需转换 |
| 完全重复行 | **1,081 行**（0.3796%），其中 19 行 Class=1 |
| 标签二值性 | 取值仅 {0, 1} |
| 零方差特征 | 无 |

### 2.2 需要处理的三个问题

1. **1,081 行完全重复**（其中 19 笔欺诈，去重后欺诈 473 笔）。
   决策：本阶段保留但打标 `is_duplicate`，阶段二建模前统一 `drop_duplicates()`——
   同一条记录若同时落入训练集与验证集，会造成指标虚高。
2. **1,825 笔零金额交易**（0.641%）。数据集无交易类型字段，无法证实业务性质（余额查询/预授权/冲正均有可能），
   因此**不做业务归因**，仅派生 `is_zero_amount` 标记，避免与真实小额交易混同。
3. **Time 只有 48 小时、无真实时钟**。所有"小时"均为相对偏移（`(Time/3600)%24`），
   结论只能表述为"相对时段"，不能对应真实凌晨/白天。

### 2.3 `Class` 字段含义确认（0/1 谁是欺诈）

依据 Kaggle 说明 1 = 欺诈，并用数据交叉验证：
`Class=1` 仅 492 笔（0.1727%），与信用卡欺诈真实发生率量级一致；
若反过来理解，则意味着 99.83% 的交易都是欺诈，与常识矛盾，可排除。

## 3. 核心数据分布

### 3.1 类别不平衡（图 1）

| Class | 笔数 | 占比 | 金额合计（€） |
|---|---|---|---|
| 0 正常 | 284,315 | 99.8273% | 25,102,462.04 |
| 1 欺诈 | 492 | 0.1727% | 60,127.97 |

不平衡比 **577.9 : 1**。欺诈金额仅占总额的 **0.239%**——
"全判正常"的模型 Accuracy 也有 99.83%，因此**本项目禁止使用 Accuracy**。

### 3.2 金额分布（图 2）

| 指标 | 值 |
|---|---|
| 中位数 / 均值 | 22.00 / 88.35 |
| P99 / P99.9 / 最大 | 1,017.97 / 3,000.00 / 25,691.16 |
| 偏度 / 峰度 | 16.978 / 845.1 |
| 零金额笔数 | 1,825（0.641%） |

强右偏、均值远大于中位数；**金额最高的 1% 交易贡献了 20.76% 的总金额**。
金额分析一律使用中位数与分位数，建模用 `log1p` 变换。

### 3.3 时段分布（图 3）

交易量最低（相对第 4 时段，2,209 笔）与最高（相对第 21 时段，17,703 笔）相差约 8 倍；
欺诈率最高的却是低谷时段：**相对第 2 时段 1.7127%、第 4 时段 1.0412%**，
为全局 0.1727% 的 **6~10 倍**。

### 3.4 两类交易的金额差异（图 4 + Mann-Whitney U 检验）

| 指标 | 正常 | 欺诈 |
|---|---|---|
| 中位数 | 22.00 | **9.25** |
| 均值 | 88.29 | 122.21 |
| P99 | 1,016.97 | 1,357.43 |
| 最大 | 25,691.16 | 2,125.87 |

- Mann-Whitney U = 61,833,399，p = 8.58e-06，**差异统计显著**；
- 但秩双序列效应量仅 **-0.1159**（|0.1| 属小效应）——显著 ≠ 可区分，**单靠金额无法识别欺诈**；
- 欺诈金额中位数只有正常交易的 **42.0%**，与"小额试探（card testing）"模式一致；
  但数据集无商户/卡字段，**无法证实该链条，只能作为与模式一致的推断**。

### 3.5 特征相关性（图 5、图 6）

- 与标签相关性 Top 5：`V17`（-0.3265）、`V14`（-0.3025）、`V12`（-0.2606）、`V10`（-0.2169）、`V16`（-0.1965）；
  正向最强：`V11`（+0.1549）、`V4`（+0.1334）；
- 29 个候选特征中 11 个 |r|>0.1、15 个 |r|<0.05（阶段二剔噪候选，需交叉验证确认）；
- **V1~V28 之间完全正交**（最大 |r|≈0），无共线性；
- **但 `Amount` 与 V2（-0.531）、V7（+0.397）、V5（-0.386）、V20（+0.339）中等相关**：
  PCA 是在含金额的原始特征上拟合的，金额信息已部分渗入主成分，阶段二需评估 Amount 的边际贡献。

### 3.6 关键特征分布对比（图 7）

| 特征 | 正常中位数 | 欺诈中位数 |
|---|---|---|
| V17 | -0.065 | **-5.303** |
| V14 | +0.052 | **-6.730** |
| V12 | +0.142 | **-5.503** |
| V10 | -0.092 | **-4.579** |

欺诈类在这几个方向上**整体大幅左移且方差远大于正常类**（从 -25 拖尾至 +7），
是全数据集最强的判别信号；但中段仍有重叠，单特征无法完全切分。

## 4. 主要分析发现（阶段一结论）

1. **数据可信可用**：零缺失、无类型问题；但信息有边界（V 匿名、Time 无时钟、无卡号），
   只能做统计建模，做不了业务归因。
2. **不平衡是核心矛盾**：1:578，且欺诈金额仅占 0.239%。评价体系必须换成
   PR-AUC / Recall@低误报率 / KS。
3. **金额不是可靠的单一信号**：与标签相关性弱（|r|<0.05）、效应量 -0.1159，
   且关系非单调——小额（含 0 元）欺诈率最高，>5,000 欧元的 55 笔**零欺诈**。
4. **时段是少数可直接使用的强特征**：相对第 2、4 时段欺诈率为全局的 6~10 倍。
5. **V17/V14/V12/V10 是最强特征**：欺诈类整体左移、拖尾长，但单特征不可完全切分。
6. **一个负面结论同样重要**：相邻交易时间间隔（全表 LAG）在两类间中位数均为 0，
   **无区分力，不作为阶段二特征**，避免浪费一轮特征工程。

## 6. 当前阶段存在的问题

| # | 问题 | 影响 | 状态 |
|---|---|---|---|
| 1 | 只有 48 小时、2 个日周期 | 时段结论的稳定性无法验证，不能外推 | 已知限制，阶段二用时间序列切分缓解 |
| 2 | V 特征匿名 | 模型结论无法做业务归因 | 阶段二用树模型特征重要性做**模型层面**解释（SHAP 未纳入本次范围） |
| 3 | 无卡号/商户字段 | 无法构造"同卡连续行为""商户集中度"等强特征 | 接受限制 |
| 4 | 1,081 行重复保留 | EDA 分布含 0.38% 重复计数 | 阶段二建模前统一去重并记录前后差异 |
| 5 | `Time` 无真实时钟 | 时段特征价值打折，且不可验证 | 已显式声明口径 |
| 6 | 成本参数未定 | 无法输出"最优阈值" | 阶段三做成可配置参数并标注为假设 |
| 7 | A3（交易间隔）分析受限 | 无卡维度，全表相邻混入跨卡切换 | 已降级为负面结论，不进特征池 |

## 7. 下一阶段（模型开发）建议

1. **切分**：按 `Time` 时间序列切分（前 70% 训练 / 后 30% 测试），禁用随机切分；
   重复行先去重。
2. **特征池**：V1~V28（可先保留全部，用模型重要性回筛）+ `log1p(Amount)` + `is_zero_amount`
   + 时段特征（`hour_of_day` 周期性编码为 sin/cos）。
   所有缩放器**只在训练集内 fit**。
3. **不平衡处理**：对比三组——不处理 / `class_weight='balanced'` / 欠采样；
   以 PR-AUC 与 Recall@1%FPR 选优；**不使用 SMOTE**（会破坏时间结构与真实分布）。
4. **模型**：逻辑回归（可解释基线）→ XGBoost（主模型）；必须给基线对比。
5. **评价**：PR-AUC、KS、Recall@固定误报率、混淆矩阵 + 阈值-召回-误报权衡曲线。
6. **可解释性**：以树模型特征重要性做模型层面解释（SHAP 归因超出三天范围，列为可选改进）。
